# Retail Sales Dashboard

This project is a Power BI dashboard built to analyse retail sales data using the Superstore dataset. It focuses on identifying key performance indicators (KPIs), category performance, regional profitability, and sales trends over time.

## Features

- Total Sales, Profit, Orders, and Average Order Value KPIs
- Interactive slicers by Region, Year, and Category
- Sales trends visualised over time
- Top-performing products by sales
- Profit breakdown by region and product category

## Files Included

- `Retail_Sales_Dashboard.pbix` – Full Power BI project file
- `Retail_Sales_Dashboard.pdf` – Exported snapshot of the dashboard visuals

## Tools Used

- Power BI Desktop
- DAX (for calculated columns and measures)
- CSV dataset (Sample Superstore)

## How to Use

1. Download the `.pbix` file
2. Open in Power BI Desktop
3. Explore filters, visuals, and report pages
